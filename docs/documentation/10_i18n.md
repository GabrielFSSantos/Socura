# Internacionalização (i18n)

Arquivo: `src/utils/i18n.ts`.

## Idioma

- Interface em **português (BR)** — locale único.
- Chaves de tradução em inglês (`runScan`, `scanCompleted`, …); valores exibidos em PT-BR.
- Não há alternância de idioma nem chave `iu_language` no `localStorage`.

## API

```ts
t("scanCompleted");
t("rateLimitPause", seconds);
t("loadCachedScan", accountCount);
```

Placeholders `%s` são substituídos na ordem dos argumentos extras.

## Uso na UI

Componentes importam `t` e chamam `t(key, ...args)` diretamente (sem prop `lang`).
