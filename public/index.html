Um único bundle para Instagram e X. Tudo roda no seu navegador — sem extensão e sem enviar dados a servidores do projeto.

  1. Copie o código com o botão abaixo.

  3. Abra o console (Ctrl+Shift+J / ⌘+⌥+I), digite allow pasting se o Chrome pedir, cole e pressione Enter.
